# Tableau-Dashboard-for-Swiggy
Swiggy: Web Traffic & Conversion Funnel Analysis
📌 Project Overview
This project involves a deep-dive analysis of Swiggy’s web traffic and user behavior patterns using Tableau. The objective was to track the end-to-end user journey from landing page to checkout, identify friction points in the conversion funnel, and optimize traffic reporting by filtering out non-human activity.

Key Insights & Features

Conversion Accuracy: Successfully identified 7.22% bot traffic distortion, allowing for a refinement of metrics that improved reported conversion accuracy from 12.6% to 13.6%.

Traffic Segmentation: Analyzed 30,110 total sessions, identifying Organic Mobile traffic as the primary volume driver at 29.39% of the total mix.

Funnel Analysis: Monitored the user journey across 10,000 conversions, achieving an overall conversion rate of 45.61% while identifying high-dropoff stages between the Product Page and Checkout.

Engagement Metrics: Tracked user health through an average bounce rate of 22.68% and an average session duration of 5 minutes, providing a baseline for UX performance.

Channel Performance: Compared traffic source performance (Paid vs. Referral vs. Direct) to assist in marketing spend optimization.

Tools Used
Data Visualization: Tableau Desktop

Analytical Techniques: Conversion Funnel Analysis, Web Traffic Filtering, Bot Detection, KPI Tracking
